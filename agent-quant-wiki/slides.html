研究 graph 與退回條件

檢查失敗會回到對應節點

  1. 取得資料實際讀取章節與定位
  2. 整理 WikiLLM 協作作者節點
  3. 查詢證據依 Wiki ID 取得主張

  5. 研究工具固定合成資料試算
  6. 結果核對算術、活動度與限制
  7. 產生教材18 頁 HTML 簡報

  • 取得資料 → 整理 Wiki → 查詢證據 → 檢查規格。
  • 通過後計算、核對結果並產生教材。
  • 缺依據回 Wiki，錯參數回規格；最多修訂兩次。

可執行的研究規格

先驗輸入，不讓錯誤進入回測

開發期的時間序列驗證

三段驗證都發生在最後測試之前

階段歷史前綴gap驗證
1[0, 22][22, 24][24, 36]
2[0, 34][34, 36][36, 48]
3[0, 46][46, 48][48, 60]

索引為從 0 起算的左閉右開區間；最終測試 [62,92)，gap [60,62)。

  • 開發前綴逐段擴張，每段驗證十二筆。
  • 每個驗證區間前保留兩筆 gap。
  • 最後測試另留三十筆，只在選擇凍結後評估。
