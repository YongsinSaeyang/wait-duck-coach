Wiki教學簡報流程與紀錄來源

Loop／graph 與實際執行紀錄

七種情境 × 前後兩種檢查位置，14 次實際重播。六個錯誤案例是故意注入，不是模型自然錯誤率。

  1. ingest取得資料章節、定位與雜湊
  2. wiki整理 Wiki概念與 claim
  3. query查詢 Wiki明列 Wiki ID 路由
  4. evidence_gate檢查證據核對 claim 與來源
  5. plan_gate檢查研究規格成本、時點與範圍
  6. research_tool研究工具合成資料計算
  7. result_gate核對研究結果算術、活動度與限制
  8. render產生教材十八頁 HTML
  9. review審閱教材來源語意與結論邊界

缺來源 ↩ 回 wiki　｜　規格不明 ↩ 回 query 釐清研究規格　｜　數字不符 ↩ 回 research_tool　｜　零交易保留限制，不靠重算消除　｜　最多兩次修訂後交人工

節點工作／執行者失敗退回重複條件

plan_gate成本、時點與範圍；程式規格檢查回 query 釐清研究規格成本缺漏／訊號時點／選擇範圍不符
research_tool合成資料計算；固定 Python 工具先回 plan_gate 核對規格資料或合法規格改變
result_gate算術、活動度與限制；程式核對數字；零交易回警示數字錯回工具；零交易補限制數字不符重算；零交易不靠反覆重算消除
render十八頁 HTML；程式建置已保存的 LLM 稿回對應的 Wiki／規格／工具節點內容修正後重新建置
review來源語意與結論邊界；人工複核待完成；重播只記錄待辦回造成問題的對應節點複核發現問題時修訂，最多兩次

本次自然觀察與優先改善節點

如果只能選一個優先改善節點，本次選「研究結果解讀」：零交易時的 0% 若被誤讀成低風險，會直接影響簡報結論。這是按影響程度排序，不是發生頻率統計。PDF 逾時與零交易各觀察一次，也沒有紀錄顯示模型真的曾寫出低風險結論。

檢查移動的理由

來源完整性在 ingest 先查；成本、訊號與測試範圍在 plan_gate 先查。result_gate 放在 render 前，核對現金流並回報零交易警示；產生教材後的 review 明列人工檢查「結論是否超過證據」，尚不是自動語意驗證器。

本次 LLM 的角色

本次 Codex 對話讀取來源、協作 Wiki 與教材。重播命令使用已保存的 LLM 作者輸出，沒有呼叫即時模型、沒有量測模型 token 或延遲，也沒有接券商。程式驗證通過不等於來源語意已獨立核實。
