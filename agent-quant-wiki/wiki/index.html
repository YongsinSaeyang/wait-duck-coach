8 篇 Wiki

W01

Agent 與研究 workflow

本作沿用文件中的架構區分：固定的路徑和條件由程式管理；當模型根據研究狀況決定下一個查詢或工具時，才有動態 Agent 的部分。

W08

研究輸出、檢查迴圈與反思

保存輸入雜湊、參數、選擇規則、來源範圍、工具結果與主張映射。正常結果、拒絕結果與重跑都要看得到。

W05

成本、成交假設與補測

每邊費率分別套用買入和賣出；本金、整股單位與費用取至分的方式事先固定。圖表中的費率是教學假設，不是任何台股券商報價。

W07

LLM 知識污染的研究風險

即使行情 CSV 按時間切好，模型也可能在訓練中讀過之後的新聞、公司結果或市場敘事。這是模型知識問題，與程式讀未來欄位不同。

W06

選參數與多重嘗試

Agent 如果很快試許多變形，再只挑最高報酬展示，讀者就看不到搜尋範圍。需保存所有候選、驗證分數與淘汰原因。

W04

時間切分與資料可用性

一筆資料的事件時間，和研究者真正能取得它的時間，可能不同。本作合成價格以此前收盤計算訊號，在下一根開盤入場，當根收盤退出。

W02

工具合約與研究權限

輸入包含 CSV 雜湊、候選均線、每邊費率、signal_lag、驗證區間和選擇範圍。輸出包含來源版本、逐筆交易、現金流、報酬、回撤及交易次數。

W03

Wiki、主張與來源的對應

七份資料都有本地章節整理和雜湊。Wiki 進一步按研究問題重組，連接概念、主張、相關頁和來源，而不是只列網址。S07 只讀摘要，其餘也保留實際讀取章節範圍。
