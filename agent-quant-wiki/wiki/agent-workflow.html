W01

Agent 與研究 workflow

概念

本作沿用文件中的架構區分：固定的路徑和條件由程式管理；當模型根據研究狀況決定下一個查詢或工具時，才有動態 Agent 的部分。

研究用途

研究問題可以由模型協助澄清，但期間、成本、可用資料與工具權限應先明列。一次生成報酬說明，不等於已完成研究。

本作邊界

Wiki 與教材由本次 Codex 對話中的 LLM 節點整理；重跑指令執行的是可重現的程式 workflow，沒有藏在後端的即時 LLM。
