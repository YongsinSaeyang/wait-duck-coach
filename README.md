# 等等鴨｜投資決策練習室

一個陪投資新手想清楚的互動網頁：整理需求、把下跌比例換成金額、練習處理模擬訊號，並記下決策理由。

## 使用方式

直接開啟 `index.html`。網站、樣式、互動程式與圖片都整合在單一檔案，不需要安裝套件。

1. **了解自己**：用六個白話問題整理目標、練習本金與對波動的想法；可以回答「不確定」。
2. **風險試算**：調整本金與下跌幅度，同時查看剩餘金額、假設損失及圖表。
3. **模擬訊號**：以虛構 DUCK 價格練習確認、忽略與等待；確認後須推進一天才檢查是否成交。
4. **決策手帳**：保存想法與當時情境；預設僅留在當次頁面，可自行選擇儲存於瀏覽器。

## 教學設定

所有價格皆為虛構情境。3 日／5 日均價與 0.1% 成本是教學假設，沒有真實行情、帳戶串接、券商下單或策略績效驗證。網頁採固定規則運作，不呼叫大型語言模型。

請使用假設金額，不要輸入帳號、密碼或證件資料。選擇不交易也是練習的一部分。

## 製作與視覺

以 AI 協助整理規格、撰寫程式、修改及測試。視覺靈感來自 Lolly Bank 的柔粉、圓角與親切風格；Logo 與等等鴨形象圖由使用者提供。本作品與銀行無品牌隸屬關係。
